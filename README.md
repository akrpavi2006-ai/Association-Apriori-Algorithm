This project implements the Apriori Algorithm for Market Basket Analysis using Python. The goal is to discover associations and relationships between products frequently purchased together by customers.

Workflow:
  1. Load transaction dataset.
  2. Handle missing values.
  3. Convert transactions into a list format.
  4. Apply Apriori algorithm.
  5. Generate association rules.
  6. Display rules with:
     - Antecedent
     - Consequent
     - Support
     - Confidence
     - Lift
    
Technologies Used:
  - Python
  - NumPy
  - Pandas
  - Matplotlib
  - Seaborn
  - Apyori
